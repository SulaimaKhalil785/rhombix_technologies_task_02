
# 🎵 Music Player – React

A clean and responsive **Music Player Web Application** built with **React** as the second internship task at **Rhombix Technologies**.

## 📌 Project Overview

This project is a simple and user-friendly music player interface that allows users to browse songs, search for tracks or artists, filter songs by category, and control music playback.

The project focuses on practicing React concepts and building an interactive frontend application.

- **Technology:** React

## ✨ Features

- 🎵 Music playlist
- 🔍 Search songs by song name or artist
- 📂 Filter songs by category
- ▶️ Play/Pause control
- ⏮️ Previous song
- ⏭️ Next song
- 🔊 Volume control
- 🎶 Now Playing / Mini Player section
- 📱 Clean and responsive user interface

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Navigate to the project folder

```bash
cd music-player
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in the terminal to view the application.
